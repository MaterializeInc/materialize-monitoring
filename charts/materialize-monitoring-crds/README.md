# materialize-monitoring-crds

CRDs for Materialize Monitoring components.
This does not install any additional resources other than CRDs.

![Version: 0.4.0](https://img.shields.io/badge/Version-0.4.0-informational?style=flat-square) ![Type: application](https://img.shields.io/badge/Type-application-informational?style=flat-square) ![AppVersion: 0.0.0](https://img.shields.io/badge/AppVersion-0.0.0-informational?style=flat-square)

## TL;DR

```bash
helm repo add materialize https://materializeinc.github.io/materialize-monitoring
helm install mz-mon-crds materialize/materialize-monitoring-crds
```

Install this before `materialize-monitoring`, and install that chart with
`--skip-crds` so the two never contend for the same CRDs.
