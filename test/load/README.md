# mz-monitoring-benchmark

Synthetic Materialize pods, each behind a ServiceMonitor, that put realistic metric and log load on the materialize-monitoring stack.

![Version: 0.1.0](https://img.shields.io/badge/Version-0.1.0-informational?style=flat-square) ![Type: application](https://img.shields.io/badge/Type-application-informational?style=flat-square)

This chart is for contributors load-testing the stack, and isn't published.
It runs one synthetic Materialize environment's worth of `mz-monitoring-benchmark` pods, each behind a `ServiceMonitor`.

## TL;DR

```bash
helm install bench test/load --namespace mzmon-bench --create-namespace
```

For sizing, scenarios, scaling, and regenerating the fixtures, see the
[load testing page](../../docs/content/reference/development/load-testing.md).
